# ZapCut 응용법 (MCP)

여러 도구를 이어 써야 하는 요청을 처리하는 방법입니다. Claude는 `recipes` 도구로 이 문서를 읽습니다. 사람이 읽어도 됩니다.
이 문서는 ZapCut 설치 폴더의 `resources\mcp\mcp-recipes.md`에도 들어 있습니다.

## 공통 원칙

- 시작 전에 `get_state`로 프로젝트·미디어·트랙을 확인합니다. 지금 열린 프로젝트를 버려야 하면(new_project) 먼저 사용자에게 묻거나 `save_project`로 저장합니다.
- **한계는 작업 전에 먼저 말합니다.** 아래 "한계" 항목에 걸리는 요청이면 시작할 때 한 문장으로 알립니다.
  - 길이 요청 예: "정확히 15초로 맞출 수는 없지만, 비슷한 길이가 되도록 편집해 보겠습니다."
- 오래 걸리는 작업(`caption`, `export`)은 시작 전에 "몇 분 걸릴 수 있다"고 알립니다.
- 편집은 단계마다 `screenshot(time)`으로 눈으로 확인합니다. 잘못되면 `undo`로 되돌립니다(사용자도 ZapCut에서 Ctrl+Z 가능).
- 구간을 지울 때는 `split_clip`+`delete_clips` 대신 **`keep_ranges`**를 씁니다. 앞의 방법은 메인 트랙만 당겨지고 자막·텍스트는 제자리에 남아 어긋납니다.
- 끝나면 결과(최종 길이, 남긴 구간과 그 이유, 저장 경로)를 짧게 보고합니다.

## 1. 특정 내용 하이라이트 (말 내용으로 구간 고르기)

요청 예: "출연자들이 OOO에 대해 말한 부분만 하이라이트로, 무음 잘라서 15초로 만들어 줘."

1. 영상을 가져와 메인 트랙에 올립니다: `import_media` → `add_to_timeline(append=true)`. 여러 파일이면 순서대로 이어 붙입니다.
2. `caption`(language=ko)으로 말소리를 받아 적습니다. 결과의 `clips[]`에 자막마다 `start`·`end`·`content`가 있습니다.
3. 받아 적은 글을 읽고 OOO를 **직접 말하거나 이어서 설명하는** 부분을 고릅니다.
   - 단어가 나온 자막 하나만 고르지 말고, 앞뒤 자막까지 보고 말이 시작하는 곳과 끝나는 곳을 찾습니다.
   - 대명사("그거", "이 제품")로 이어지는 말도 맥락상 같은 이야기면 포함합니다.
   - 음성 인식은 고유명사를 틀리게 적을 수 있습니다. 발음이 비슷한 표기(예: 영어 이름의 한글 표기)도 찾습니다.
4. 고른 구간을 `keep_ranges`로 남깁니다. 문장이 잘리지 않게 각 구간 앞뒤에 0.2초쯤 여유를 둡니다. 자막도 함께 남고 시간이 맞춰집니다.
5. 무음을 잘라냅니다: 먼저 `cut_silence(apply=false)`로 줄어들 길이(`after`)를 보고, 괜찮으면 `cut_silence()`로 적용합니다.
6. 목표 길이에 맞춥니다(2번 응용법).
7. 필요하면 포맷을 바꾸고(`reframe` ratio=9:16, anchor=face) `screenshot`으로 구도를 확인합니다.
8. `export(path)`로 내보내고, 사용자가 원하면 `save_project`로 저장합니다.

목적이 주어지면(예: "보는 사람이 창업하고 싶게") 구간 선택과 순서를 그 목적에 맞춥니다. 시선을 끄는 숫자나 결과로 시작하고, 근거를 거쳐, 앞으로의 기대로 끝내는 식입니다. 첫 장면에 제목(`add_text`)을 넣을 때는 **영상에서 실제로 나온 말과 숫자만** 씁니다. 과장하거나 지어내지 않습니다.

OOO 언급이 거의 없거나 전혀 없으면 억지로 채우지 말고, 찾은 만큼의 길이와 이유를 알린 뒤 사용자에게 어떻게 할지 묻습니다.

## 2. 목표 길이 맞추기 (15초, 1분 등)

정확한 길이는 보장할 수 없습니다. 무음을 자르면 길이가 다시 줄고, 문장 중간에서 자르면 어색하기 때문입니다. **작업 전에 사용자에게 "비슷한 길이로 맞추겠다"고 알립니다.**

1. 구간을 고를 때 무음으로 줄어들 몫을 생각해 목표보다 20~30% 길게 고릅니다.
2. `keep_ranges` → `cut_silence(apply=false)`로 `after`를 확인합니다.
3. 길이를 조정합니다.
   - 많이 길면: 덜 중요한 구간을 빼고 다시 고릅니다(`undo` 후 `keep_ranges`를 다시 실행하거나, 지금 타임라인 기준으로 `keep_ranges`를 한 번 더).
   - 조금 길면: 지금 타임라인에서 문장이 끝나는 자리(자막의 end)를 찾아 `keep_ranges`로 끝을 다듬습니다.
   - 짧으면: `undo`로 돌아가 구간을 더 넣습니다.
4. 문장이 끝나는 자리에서 끊는 것을 길이보다 우선합니다. 목표 ±10% 안이면 충분합니다.
   - 배경음악·현장 소음이 깔린 영상이나 말이 빽빽한 인터뷰는 `cut_silence`가 거의 줄이지 못합니다(`apply=false`에서 ranges가 비거나 1~2초). 이때는 무음 몫을 빼지 말고 처음부터 목표 길이에 가깝게 구간을 고릅니다. `noise_db`를 많이 올리면(-25 이상) 작은 말소리까지 잘릴 수 있습니다.
   - 같은 내용을 되풀이하는 자막("8천 조금 안 됐어요 / 8천 조금 안 나왔고")이나 군더더기 설명은 빼서 줄입니다. 질문과 답이 짝을 이루게 남기면 짧아도 맥락이 삽니다.
   - 자동 캡션의 시간은 말 앞뒤 쉼까지 넉넉하게 잡히는 경우가 많습니다. 구간 시작이 길게 비어 보이면 그 부분만 줄입니다.
5. 속도를 올려(`update_clip` speed) 길이를 맞추는 방법은 사용자가 동의할 때만 씁니다.

## 3. 인터뷰·브이로그 템포 정리 + 자막

1. `caption` → 자막 내용을 훑어 잘못 적힌 단어를 `update_clip(id, {text: {content}})`로 고칩니다.
2. `cut_silence(apply=false)`로 잘릴 양을 확인하고 적용합니다. 자막은 함께 정리됩니다.
3. 필요하면 `export_srt`로 자막 파일을 저장합니다.
4. 순서를 지킵니다: `caption`을 먼저 하고 `cut_silence`를 해야 자막이 함께 정리됩니다.

## 4. 롱폼 → 숏폼·여러 포맷

1. `reframe(ratio="9:16", anchor="face")` → `screenshot` 몇 장면으로 인물이 화면 안에 있는지 확인합니다.
   - 인물이 둘 이상이거나 잘리면 `fit="box"`(위아래 흐린 배경)로 바꿉니다.
2. `export` → `undo`로 원래 비율로 돌아가 다음 포맷(1:1 등)을 반복합니다.

## 5. 장면별 소제목·요약 자막

1. `caption`으로 받아 적은 내용을 읽고 이야기가 바뀌는 지점을 나눕니다.
2. 각 지점 `start`에 `add_text_template` 또는 `add_title`로 소제목을 넣습니다(목록은 `list_library`).
3. 핵심 단어만 색을 바꾸려면 `add_text`의 `style.runs`([{start, end, color}], 글자 위치 기준)를 씁니다.

## 6. 사진·클립 모음 영상

- 빠르게: `import_media`로 여러 장 → `apply_template`(목록은 `list_library templates`)
- 직접: `add_to_timeline(append=true)` → 클립마다 `update_clip`의 transition → `add_sound(fill=true)`로 배경음악

## 7. 영상의 소리만 따로 다루기

요청 예: "영상 소리를 따로 떼서 끝에 3초 페이드 아웃", "소리는 두고 화면만 바꿔 줘".

1. `get_state`로 영상 클립 id를 찾고 `detach_audio(ids)`로 소리를 오디오 트랙에 떼어 냅니다. 원래 영상 클립은 음소거됩니다.
2. 돌려받은 `audio_clip_ids`를 `update_clip`(volume·fadeIn·fadeOut·start·duration)이나 `split_clip`으로 다듬습니다.
3. 떼어 낸 소리는 영상 클립과 묶이지 않습니다. 이후 메인 트랙 클립을 옮기거나 지우면 오디오 클립도 같이 맞춥니다. 구간을 잘라낼 때는 모든 트랙을 함께 자르는 `keep_ranges`·`cut_silence`를 씁니다.
4. 되돌리려면 오디오 클립을 지우고 영상 클립을 `update_clip`(muted=false)로 풉니다(바로 직후라면 `undo`).

## 한계 (사용자에게 미리 알릴 것)

- **길이**: 목표 길이에 "비슷하게"만 맞춥니다(2번 응용법).
- **화자 구분 불가**: 음성 인식은 누가 말했는지 나누지 않습니다. "A 출연자가 말한 부분만" 같은 요청은 말 내용과 맥락으로 추정할 뿐 정확하지 않습니다.
- **화면 내용**: 영상 전체를 보지 않습니다. `screenshot`으로 몇 장면만 볼 수 있으니, "웃는 장면만" 같은 화면 기준 요청은 말 내용으로 대신 찾거나 확인할 장면 수를 정해 둡니다.
- **긴 영상의 자동 캡션**: `caption`은 끝날 때까지 기다리는 도구라 긴 영상(수십 분 이상)은 클라이언트 시간 제한에 걸릴 수 있습니다. 필요한 부분만 먼저 잘라 올리거나 짧은 파일로 나눠 달라고 합니다.
- **고유명사 인식**: 사람·제품 이름은 틀리게 적힐 수 있습니다.
- 내보내기는 한 번에 하나만 됩니다.
