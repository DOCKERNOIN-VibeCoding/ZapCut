# 짭컷 클린룸 기능 명세서 v0.1

이 문서는 **분석(더티룸) 결과물**입니다. 구현 쪽은 이 문서만 보고 코드를 작성합니다.
출처는 CapCut 데스크톱에서 관찰할 수 있는 동작과 공개 도움말, ReaCut(MIT)의 공개 기능 목록, 그리고 ReaCut과 CapCut을 비교한 블로그 글(2026)입니다.
CapCut의 코드, 에셋, 문구, 아이콘은 사용하지 않습니다. 모든 화면 문구는 짭컷 고유의 한국어로 씁니다.

## 1. 화면 구성 (일반적인 4분할 편집기 배치)

```
┌───────────────────────────── 상단바: 로고 · 프로젝트 이름 · 실행취소/다시실행 · [내보내기] ─┐
│ 리소스 패널(좌상)          │ 플레이어(중앙)                 │ 속성 패널(우측)              │
│ 탭: 미디어 오디오 텍스트    │ 캔버스 · 재생/정지 · 시간표시   │ 선택한 클립의 속성 탭         │
│ 스티커 효과 전환 필터 조정  │ 화면비 선택 · 전체화면          │ (화면/오디오/속도/애니/조정)  │
├────────────────────────────────────────────────────────────────────────────────┤
│ 타임라인 도구모음: 선택 · 분할 · 왼쪽삭제 · 오른쪽삭제 · 삭제 · 정지프레임 · 역재생 · 미러 │
│                    … 메인트랙 자석 · 스냅 · 연동 · 확대/축소 슬라이더                  │
│ 트랙(위→아래): 텍스트/스티커 → 오버레이 비디오 → [메인 트랙] → 오디오                    │
└────────────────────────────────────────────────────────────────────────────────┘
```

- 어두운 회색 테마를 쓰고 강조색은 청록 계열(짭컷 고유 색)로 합니다.
- 패널 경계선을 드래그해 크기를 조절할 수 있습니다.

## 2. 핵심 동작 규칙

| ID | 규칙 |
| --- | --- |
| T1 | **메인 트랙 자석**(켜기/끄기): 메인 트랙의 클립은 0초부터 빈틈 없이 이어 붙입니다. 클립을 지우거나 줄이면 뒤 클립이 당겨지고, 드래그하면 놓은 위치를 기준으로 순서가 바뀝니다. |
| T2 | **스냅**(N 키): 클립 경계와 재생헤드가 다른 클립의 경계나 재생헤드 근처(화면 기준 8px)에 오면 달라붙습니다. |
| T3 | 오버레이·텍스트·오디오 트랙에서는 자유롭게 배치합니다. 겹치는 위치에 놓으면 새 트랙을 자동으로 만듭니다. |
| T4 | 분할(Ctrl+B)은 선택한 클립(선택이 없으면 재생헤드 아래의 모든 클립)을 재생헤드 위치에서 둘로 나눕니다. |
| T5 | 왼쪽 삭제(Q)는 재생헤드 앞부분을, 오른쪽 삭제(W)는 뒷부분을 잘라냅니다. |
| T6 | 미디어를 타임라인 빈 곳에 끌어 놓으면 메인 트랙(비어 있으면) 또는 새 오버레이 트랙에 놓입니다. 오디오는 오디오 트랙에 놓입니다. |
| T7 | 모든 편집은 실행취소(Ctrl+Z)와 다시실행(Ctrl+Shift+Z / Ctrl+Y)을 할 수 있습니다. |
| T8 | 프로젝트 화면비는 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 중에서 고릅니다. 새 프로젝트를 만들 때 비율·해상도(짧은 변 480~2160)·프레임 속도를 정하고, "첫 소스에 맞춤"을 고르면 첫 클립의 비율을 따릅니다. 내보내기는 프로젝트 해상도에서 시작합니다. *(추가: 시작 시 틀 선택)* |

## 4. 기능 범위와 단계

○ = 이번 단계 목표 · ReaCut 대비 **추가**는 블로그 비교표에서 △/× 였던 항목입니다.

### 1단계 — 핵심 편집기 (MVP)
- 미디어 가져오기(비디오/오디오/이미지), 썸네일, 파형
- 다중 트랙 타임라인, 메인 트랙 자석, 스냅, 이동/트림/분할/삭제, Q/W, 실행취소
- 플레이어 실시간 합성(비디오/이미지/텍스트), 위치·크기·회전·불투명도
- 기본 조정(밝기/대비/채도), 볼륨·페이드, 배속(0.1~10배)
- 텍스트 클립(글꼴, 크기, 색, 외곽선, 배경)
- MP4(H.264/AAC) 내보내기(해상도·프레임레이트·품질), 진행률
- `.zapcut` 저장/열기, 자동 저장, **한국어 기본 UI**, **Windows NSIS 설치 파일**

#### 미리보기 = 내보내기 보장 방식
- 색: 조정·필터·LUT를 3D LUT 하나로 구워 WebGL과 FFmpeg `lut3d`가 같은 파일을 사용
- 움직임: 키프레임·애니메이션을 FFmpeg 수식 문자열로 만들고, 미리보기는 같은 수식을 해석기로 계산 (`aevalsrc` 대조 테스트)
- 마스크: 수식 하나를 FFmpeg `geq`와 미리보기 텍스처 생성에 공용
- 전환·효과: `xfade` 등의 실제 출력을 측정해 셰이더를 맞추고, 전 종류를 FFmpeg로 렌더링하는 통합 테스트로 검증
