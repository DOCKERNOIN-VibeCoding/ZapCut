# 타이틀 템플릿 명세 (v1.1)

영상 첫 화면, 장면 제목, 장소·날짜 표시에 쓰는 **여러 레이어로 된 움직이는 제목**. 텍스트 템플릿(한 줄 텍스트 + 스타일)과 별도로,
텍스트 탭의 '타이틀 템플릿'에 둔다. 구조와 동작은 짭컷이 정한 것이고, 이름·문구·디자인은 모두 짭컷 고유로 새로 만든다.

## 1. 데이터

- 타이틀 = 레이어 배열. 그리는 순서 = 배열 순서.
- 레이어 = 텍스트 또는 도형(사각형·타원·선·호·SVG 경로). 위치는 1080p 기준 px, 타이틀 중심이 원점.
- 텍스트 레이어는 이름표(`label`: "제목", "부제", "날짜" 등)가 있어 속성 패널에서 문구를 따로 고친다.
- 도형은 텍스트 레이어에 **크기를 맞추거나**(`fit`: 여백 포함) **옆에 붙을** 수 있다(`attach`: 왼쪽/오른쪽/위/아래 + 간격). 문구가 길어지면 장식이 따라간다.
- 클립에는 템플릿 정의를 복사해 둔다. 템플릿을 나중에 고쳐도 기존 프로젝트는 그대로다.

## 2. 애니메이션

- 레이어마다 등장(`in`)·퇴장(`out`)·반복(`loop`).
- 등장은 **클립 시작**, 퇴장은 **클립 끝** 기준으로 시각을 잡는다 → 클립 길이를 바꿔도 등장·퇴장이 유지된다.
- 등장/퇴장 = 시작 시각, 길이, 이징(선형·가속·감속·가감속·튕김·탄성), 제자리 대비 상태(위치·크기·가로/세로 배율·회전·불투명도).
- 단위 애니메이션: 글자·단어·줄 단위로 같은 움직임을 시간차(`stagger`)를 두고 적용. 순서 = 왼→오, 오→왼, 가운데부터, 양끝부터, 무작위(고정 시드).
- 드러내기 효과: 타자기, 무작위 문자 해독(scramble), 닦아내기(왼쪽·오른쪽·위·아래·가운데), 선 그리기(도형 외곽선).
- 반복: 깜빡임, 맥박, 둥실, 회전, 흔들림.

## 3. 렌더링과 출력

- `renderTitle(title, T, D, Href)` 하나로 미리보기 텍스처, 썸네일, 내보내기 PNG를 모두 그린다 (같은 입력 → 같은 그림, 무작위는 시드 고정).
- 캔버스 크기는 애니메이션 범위까지 포함해 고정 → 프레임마다 크기가 바뀌지 않는다.
- 내보내기는 움직이는 구간(등장 끝까지, 퇴장 시작부터, 반복이 있으면 전체)만 프레임마다 PNG, 가운데 정지 구간은 한 장.
- 날짜·시간 자리표시(`{YYYY}`, `{MM}`, `{DD}`, `{MON}`, `{Week}`, `{요일}`, `{HH}:{mm}` 등)는 넣는 순간 오늘 날짜로 바뀐다.

## 4. 화면

- 텍스트 탭 = 텍스트 템플릿 / 타이틀 템플릿 / 기본.
- 타이틀 템플릿 썸네일은 같은 렌더러로 그리고, 마우스를 올리면 등장 애니메이션을 재생한다.
- 타이틀 클립 속성 = '타이틀'(레이어별 문구) + '화면'(위치·크기·회전·불투명도).
