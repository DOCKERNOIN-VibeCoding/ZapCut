# ZapCut × Claude 연결 가이드

Claude에게 말로 시키면 ZapCut이 영상을 편집합니다. 미디어 가져오기, 컷 편집, 자막, 포맷 변환(16:9 → 9:16), 내보내기까지 Claude가 대신 처리합니다.

ZapCut 창은 그대로 열려 있으므로 Claude가 편집하는 과정을 화면에서 직접 볼 수 있고, 마음에 들지 않으면 **Ctrl+Z**로 되돌리면 됩니다.

---

## 준비물

| 항목 | 내용 |
| --- | --- |
| ZapCut | **v1.2.0 이상** (상단 로고를 눌러 버전 확인. 낮으면 다시 켜서 자동 업데이트) |
| Claude 앱 | **Claude Desktop**(Windows 앱) 또는 **Claude Code**(터미널) 중 하나 |
| 별도 설치 | 필요 없음. Node.js 등을 따로 깔지 않아도 됩니다 |

> ⚠️ claude.ai 웹사이트와 모바일 앱으로는 연결할 수 없습니다. ZapCut은 내 PC 안에서만 연결을 받기 때문에, 같은 PC에 설치한 Claude Desktop이나 Claude Code가 필요합니다.

---

## 1단계. ZapCut에서 외부 제어 켜기

1. ZapCut을 실행합니다.
2. 화면 **상단의 ZapCut 로고**를 눌러 정보 창을 엽니다.
3. **외부 제어 (MCP)** 항목에서 **"Claude 같은 외부 프로그램이 이 프로그램을 조종할 수 있게 허용"**을 체크합니다.
4. 체크하면 아래에 등록 명령과 **복사**, **JSON**, **Claude에 바로 등록** 버튼이 나타납니다. 다음 단계에서 씁니다.

> 💡 이 설정은 기본으로 꺼져 있습니다. 켜도 이 PC 안(127.0.0.1)에서만 연결할 수 있고, 무작위 토큰으로 보호됩니다. 체크를 풀면 연결 통로가 바로 닫힙니다.

---

## 2단계. Claude에 ZapCut 등록하기

등록은 처음 한 번만 하면 됩니다.

### 가장 쉬운 방법: Claude에 바로 등록

1. ZapCut 정보 창에서 **Claude에 바로 등록** 버튼을 누릅니다.
2. ZapCut이 이 PC의 Claude Code와 Claude 데스크톱 앱(채팅)을 찾아 둘 다 등록합니다. 결과는 "Code 등록 완료", "채팅 등록 완료"처럼 항목별로 표시됩니다. 설치되지 않은 쪽은 건너뜁니다.
3. **Claude를 완전히 종료한 뒤 다시 시작합니다.** 창만 닫으면 트레이에 남아 있으니, 작업 표시줄 오른쪽 트레이 아이콘을 우클릭해 **종료**하세요.

버튼이 실패하거나 직접 등록하고 싶다면 아래 **A**(Claude 데스크톱 앱) 또는 **B**(Claude Code)를 따라 하세요.

### A. Claude Desktop을 쓰는 경우 (직접 등록)

1. ZapCut 정보 창에서 **JSON** 버튼을 눌러 설정 내용을 복사합니다.
2. Claude Desktop에서 **설정 → 개발자(Developer) → 구성 편집(Edit Config)**을 누릅니다. `claude_desktop_config.json` 파일이 있는 폴더가 열립니다. (홈페이지에서 받은 설치본은 `%APPDATA%\Claude`에 있지만, Microsoft Store 설치본은 위치가 다르니 이 메뉴로 여는 것이 정확합니다)
3. `claude_desktop_config.json`을 메모장으로 열고 복사한 내용을 붙여 넣은 뒤 저장합니다.

파일이 비어 있거나 처음이라면 복사한 내용을 그대로 붙여 넣으면 됩니다. 모양은 다음과 같습니다(경로는 PC마다 다르니 반드시 **JSON 버튼으로 복사한 값**을 쓰세요).

```json
{
  "mcpServers": {
    "zapcut": {
      "command": "C:\\...\\ZapCut\\ZapCut.exe",
      "args": ["C:\\...\\ZapCut\\resources\\mcp\\zapcut-mcp.cjs"],
      "env": { "ELECTRON_RUN_AS_NODE": "1" }
    }
  }
}
```

이미 다른 MCP 서버가 등록돼 있다면, 파일 전체를 덮어쓰지 말고 기존 `mcpServers` 안에 `"zapcut": { ... }` 부분만 쉼표로 이어서 추가합니다.

```json
{
  "mcpServers": {
    "기존서버": { "...": "..." },
    "zapcut": {
      "command": "...",
      "args": ["..."],
      "env": { "ELECTRON_RUN_AS_NODE": "1" }
    }
  }
}
```

4. Claude Desktop을 **완전히 종료**한 뒤 다시 켭니다. 창만 닫으면 트레이에 남아 있으니, 작업 표시줄 오른쪽 트레이 아이콘을 우클릭해 **종료**하세요.
5. 대화 입력창의 도구(🔨 또는 커넥터) 메뉴에 **zapcut**이 보이면 연결된 것입니다.

### B. Claude Code를 쓰는 경우 (명령 붙여 넣기)

1. **복사** 버튼을 눌러 등록 명령을 복사합니다. 모양은 다음과 같습니다.

```
claude mcp add zapcut -s user -e ELECTRON_RUN_AS_NODE=1 -- "C:\...\ZapCut.exe" "C:\...\resources\mcp\zapcut-mcp.cjs"
```

2. Claude Code 대화창이나 PowerShell·명령 프롬프트에 붙여 넣고 실행합니다.
3. `claude mcp list`를 실행해 목록에 **zapcut**이 보이면 완료입니다.

> ⚠️ 이 명령은 **Claude Code에만** 등록됩니다. Claude 채팅에서도 쓰려면 명령을 붙여 넣을 때 Claude Code에 "채팅에서도 쓸 수 있게 등록해 줘"라고 함께 요청하세요. (정보 창의 빨간 **(?주의)**에 마우스를 올려도 같은 안내가 나옵니다.)

> 💡 터미널에서 "claude를 찾을 수 없다"는 오류가 나면 Claude Code가 PATH에 잡혀 있지 않은 것입니다. **Claude에 바로 등록** 버튼을 쓰면 PATH와 상관없이 등록됩니다.

## 3단계. Claude에게 말로 시키기

ZapCut이 꺼져 있어도 Claude가 명령을 보내면 ZapCut이 자동으로 켜집니다. 파일 위치는 **전체 경로**로 알려 주는 것이 정확합니다.

**기본 편집**

- "`D:\촬영\0915` 폴더의 영상 세 개를 순서대로 이어 붙이고, 앞에 '제주 브이로그' 타이틀을 넣어 줘."
- "지금 타임라인 상태를 알려 줘."
- "두 번째 클립을 10초 지점에서 잘라서 뒷부분은 지워 줘."

**자막·템포 정리**

- "말소리로 자동 자막을 만들고, 자막은 화면 아래쪽에 노란색으로 해 줘."
- "말 사이 빈 구간을 잘라내서 템포를 빠르게 해 줘."
- "자막을 `D:\out\vlog.srt`로 저장해 줘."

**포맷 변환·내보내기**

- "이 16:9 영상을 얼굴 기준으로 9:16 쇼츠로 바꾸고, 화면을 캡처해서 구도를 확인해 줘."
- "16:9, 9:16, 1:1 세 가지로 각각 `D:\out` 폴더에 내보내 줘."
- "1080p 고화질 MP4로 `D:\out\final.mp4`에 내보내고, 프로젝트도 저장해 줘."

**꾸미기**

- "어떤 전환 효과가 있는지 보여 주고, 클립 사이에 어울리는 걸 넣어 줘."
- "끝까지 배경음악을 깔고 볼륨은 낮게 해 줘."
- "가져온 사진들로 영상 템플릿을 적용해 줘."

## 잘 쓰는 팁

- **눈으로 확인시키기**: "화면 캡처해서 확인해 줘"라고 덧붙이면 Claude가 미리보기를 직접 보고 자막 위치나 구도를 고칩니다.
- **되돌리기**: Claude가 한 편집은 ZapCut에서 Ctrl+Z로 되돌릴 수 있습니다. Claude에게 "방금 거 취소해 줘"라고 해도 됩니다.
- **여러 포맷 뽑기**: 한 번에 "16:9, 9:16, 1:1로 각각 내보내 줘"라고 하면 Claude가 포맷마다 변환 → 내보내기 → 원래대로 되돌리기를 반복합니다.
- **자동 캡션 첫 실행**: 처음 한 번 음성 인식 모델(약 190MB~574MB)을 내려받느라 시간이 걸립니다.
- **긴 내보내기**: 영상이 길면 내보내기에 몇 분이 걸립니다. 그동안 ZapCut을 끄지 마세요.

## 문제 해결

| 증상 | 해결 |
| --- | --- |
| "ZapCut이 실행 중이지 않거나 외부 제어가 꺼져 있습니다" | ZapCut 정보 창에서 **외부 제어 허용**이 체크돼 있는지 확인하세요. |
| Claude 명령에 아무 반응이 없음 | ZapCut 화면에 "복구할까요?" 같은 확인 창이 떠 있으면 먼저 답해 주세요. 창이 떠 있는 동안에는 명령이 처리되지 않습니다. |
| Claude Desktop에 zapcut이 안 보임 | ① Claude Desktop을 트레이에서 완전히 종료 후 재실행 ② `claude_desktop_config.json`의 쉼표·괄호가 맞는지 확인 ③ JSON 버튼으로 다시 복사해 붙여 넣기 |
| Claude Code에서 다른 폴더로 옮기니 안 됨 | 등록할 때 `-s user`를 넣지 않았기 때문입니다. 2단계 B의 팁대로 다시 등록하세요. |
| ZapCut을 다른 폴더에 다시 설치함 | 경로가 바뀌었으니 정보 창에서 명령/JSON을 다시 복사해 등록하세요. |
| 그만 쓰고 싶음 | 정보 창에서 **외부 제어 허용** 체크를 풀면 즉시 연결이 막힙니다. 등록 자체를 지우려면 Claude Code는 `claude mcp remove zapcut`, Claude Desktop은 설정 파일에서 `zapcut` 부분을 지웁니다. |

## 고급: 명령줄에서 직접 부르기

Claude 없이 스크립트에서 ZapCut을 조종할 수도 있습니다. 결과는 JSON으로 출력됩니다.

```
ZapCut.exe --mcp tools                                   # 도구 목록
ZapCut.exe --mcp call get_state                          # 현재 상태
ZapCut.exe --mcp call export '{"path":"C:\\out.mp4"}'    # 내보내기
ZapCut.exe --mcp call screenshot --out shot.png          # 미리보기 캡처
```

> VS Code 안의 터미널처럼 `ELECTRON_RUN_AS_NODE=1`이 이미 설정된 환경에서는 `--mcp` 대신 2단계 B의 명령처럼 `zapcut-mcp.cjs` 파일 경로를 직접 지정하세요.
